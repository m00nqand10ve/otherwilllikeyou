# 第三幕 · 晚间广播

双击 `broadcast.html` 就能玩。不用构建、不用服务器、不用联网。

## 玩法

从第二幕过场进入时：两人已坐在同一张播音桌前 → 试音（校准）→ 选档 → 三分钟广播 → 灯灭 → 完成卡。单独打开本页时保留简短进门开场。

广播稿本身就是谱面。稿子被切成词块，一块一个音符，从画面上方落到判定线。
粉轨是朱里，蓝轨是和臣。她那条轨道自动命中——**你只需要管自己那条**。

| 操作 | 键 |
| --- | --- |
| 按下（Tap / 接力 / 长按 / 双人块起手） | `J` = 高音，`F` = 低音；教学段（试音后前两小节）`空格` 也等价；点画面自动对上音高 |
| 松开（长按 / 双人块收尾） | 抬起按键 |
| 对白推进 | `E` / `Enter` / `空格`，或点画面 |
| 试音时跳过校准 | `Enter` |
| 试音后选档 | `F` / `1` 选演播，`J` / `2` 选电台，`Enter` 用上次的档 |
| 离开（随时） | `Esc` 或右上角「离开」 |

## 高低音：J 高、F 低

每个词块都带一个音高，由 `chart.js` 按它在句中的语调位置推导：**句首 / 上扬 → hi，收尾 / 落点 → lo**。
`script.js` 里也可以显式覆盖：`T("……", 1, "hi")`。

玩家轨在判定线上分上下两格：上格是 J（高音），下格是 F（低音），音符落在哪格就按哪个键。
`空格` 只在教学段（试音后的前两小节）继续等价；之后按错键位 = **错键**：
计一次 miss 的惩罚，但判定字写「错键」而不是「MISS」——漏按和按错要分得出来。

## 四种音符 + 两种特殊块

| 形状 | 名字 | 含义 | 怎么打 |
| --- | --- | --- | --- |
| 实心块 | Tap | 起一句、或者重读一个词 | 点一下 |
| 带尾巴的长条 | Hold | 一句长话，要一口气念完 | 按住，尾巴走完再松 |
| **没有音符** | Rest | 逗号、句号、换气 | **不要按**。按了不加分，还会让电流声变大 |
| 粉色左端 + 一道桥 | Relay | 她念到一半停了，这句归你 | 桥连到你轨道时按下，等于接上她的话 |
| 金边、跨两条轨道 | Both | 收尾那句两个人一起按住 | 她先按住（自动），你在 300ms 内按下，两人在 ±200ms 内一起松手 |
| 小菱形 | Grace | 副歌第二遍弱拍上的装饰音 | 打中 +50 分；漏了不扣分、不断连击 |

**Both（双人长按）** 落在最后一句「下次见。」上：粉轨那个音符她自动按住，
蓝轨这个你要在 300ms 的按下窗里跟上（提前 100ms 也允许抢按），然后和她一起松手。
松手时间差在 ±200ms 内才算「收尾同步」，完成卡上会单独有一行。

**Grace（装饰音）** 只出现在点歌段后半（副歌第二遍）的弱拍上，不占正常谱面的位置，
也不进准确率的分母——它是给熟手的加分项。

## 两档难度

试音结束后选，存在 `act3-difficulty-v1`（缺省「演播」）。两档共用同一次校准出来的 `offsetMs`。

| 档 | PERFECT | GOOD | OK | 下落提前量 | 噪音影响 |
| --- | --- | --- | --- | --- | --- |
| **演播**（默认） | ±45ms | ±110ms | ±250ms | 1.55s | 只影响演出 |
| **电台** | ±35ms | ±80ms | ±150ms | 1.25s | 噪音到 80 会触发救援 |

长按另外算：松手时按住了不到 85% 的时长，按缺的比例扣一点分，但档位不改——档位是按下那一刻定的。

**末段加速**：谱面最后一节起，BPM 96 → 108（音频的鼓、贝斯、人声一起变速），
收尾段的下落提前量缩到 1.25s。前面段落不动。

## 电流噪音计

画面右下（判定线右端）有一根细噪音条，0–100：

| 来源 | 变化 |
| --- | --- |
| 空按（附近没有你的音符） | +12 |
| 在 Rest 里按 | +18 |
| 错键 | +8 |
| 每小节自然衰减 | −6 |

- **≥50**：她那一行音符变灰，画面蒙灰、飘雪花点，字幕条也带雪花点。
- **≥80（电台档）**：她替你接住下一句（粉轨补一个「托」的音符，只有她的音色），噪音回落到 40。
  演播档不触发救援，只改演出与结算措辞——她的轨道永远是稳的。

## 突发段：稿纸乱序

点歌段里会插入 4 小节「稿纸被碰乱」：**谱面照常按拍子落，字幕词块顺序被打乱并标红**。
这时候不能背稿，只能读谱面。由种子决定是否触发（**首通必触发一次**，之后 50%），
判定规则不变，台词一个字不改。

## 结算与剧情回响

完成卡按既有五段（试音 / 开场 / 来电 / 点歌 / 收尾）各出一行：
准确率、接力接住数（x/y）、该段最高连击、以及「收尾同步」有没有对上。
总评级规则不变（仍看总准确率）。

存档分两个新键：

- `act3-difficulty-v1`：本次选的档（`演播` / `电台`）。
- `act3-result-v1`：结算 JSON，第四幕开场按它换台词：
  `{ difficulty, rank, accuracy, score, maxCombo, relaysCaught, relaysTotal, syncBoth, maxNoise, rescues, segments: [{ name, accuracy, relaysCaught, relaysTotal, maxCombo }...] }`

开场念稿前，朱里会按第二幕过场接住的稿纸数说一句小动作字幕（读 `our-story-bridge-papers-v1`，
0–3，缺省按 3 = 全接住）。只改字幕，不碰谱面和判定。

## 她怎么帮你（四处，全都不写字）

1. **漏接接力**。音乐不停，粉轨上多出一个音符，她那句就替你说完了；字幕里那半句变成她的粉色。
   你能听见音色换了人：她是带通三角波，你是方波，同一个五声音阶——不用看提示也知道谁在说。
2. **一长串全是你的**。她敲一下稿纸（有纸响），接下来四五个音符外面套一层虚线，一闪一闪。
   不是 buff，只是提前告诉你「下面这段你自己来」。
3. **最后一句**。两条轨道在同一个拍点落下，字幕合成一行「两人」；双人块还要一起松手。
4. **电流声太大**（电台档）。她不说话，只是把下一句接过去——粉轨多一个「托」的音符，噪音跟着落回去。

没有「她救了你」这种字。漏了就漏了，广播继续。

## 试音

进正片之前有 12 下节拍器。跟着敲 8 下空格，取偏差的中位数当输入延迟，写进 `localStorage`，
下次进来直接用。敲不满 8 下也没关系，到点自动往下走（当 0 延迟处理）。

它校准的是「你听到的」和「你按下的」之间的差，不是判定窗口。所以戴耳机和不戴耳机，
这个值会差几十毫秒——这就是要单独测一次的原因。

## 文件

| 文件 | 作用 |
| --- | --- |
| `broadcast.html` | 入口。普通 `<script>`，`file://` 直接能跑 |
| `broadcast.css` | 界面。广播稿条固定在画布**下面**，`--scrh: 64px`，不随字数变高 |
| `audio.js` | 音频时钟 + 全部音色 + 末段变速。BGM、鼓、贝斯、人声「嘟」、纸响、灯亮，全是运行时合成的 |
| `script.js` | 广播稿。按**拍**写；词块、停顿、接力、双人块、五段分界都在这里 |
| `chart.js` | 谱面生成：词块 → 音符（含音高）、字幕行、提示点、补位点、停顿窗口、装饰音、突发段。纯函数，随机只走种子 |
| `rhythm.js` | 判定、计分、两档窗口、错键/漏按、噪音计、双人块、五段统计、她的轨道、补位。纯逻辑，不碰 DOM 也不碰 Canvas |
| `scene3.js` | 复用第二幕单桌广播室背景、镜头、两条轨道、字幕条、档位选择、噪音演出、结算卡、流程状态机 |
| `tools/check.cjs` | 自检，截图落在 `tools/out/` |
| `tools/shots.cjs` | 演示截图 `d1`–`d11`，用 `_seek()` 跳段，不用真等三分钟 |

## 自检

```bash
node act3/tools/check.cjs
```

六组：

1. **谱面**——时长、密度、三种音符、五段覆盖全部稿子行、音高推导（句首 hi / 收尾 lo）、
   教学段 8 拍、末段 108 BPM + 1.25s、both 块、装饰音位置（不撞正常音符和长按）、
   突发段四小节对齐且字幕真的乱序但不改字、停顿窗口、提示点、补位点、
   **同稿同种子两次生成逐事件相等**。
2. **两档判定窗**——演播 ±45/110/250ms、电台 ±35/80/150ms 的边界各自生效。
3. **F/J**——按对命中、按反错键（+8 噪音、单独计数）、漏按记 miss；
   空格只在教学段等价；both 块 F/J 都算对；点画面自动对音高。
4. **噪音计**——空按 +12、Rest +18、错键 +8、每小节 −6、上下限；
   演播 ≥80 只演出，电台 ≥80 触发一次救援并回落 40，补位音符到点命中。
5. **both 窗口**——按下 300ms / 提前 100ms / 松手 ±200ms 的边界逐一验；
   她那一侧自动按住；按住到自动松手也能算同步。
6. **判定 / 计分 / 救场 / 五段**——第一个 PERFECT 正好 1000 分、GOOD/OK/MISS、
   长按按满 vs 松太早、漏接力 → 补位 → 补位音符命中、接住了就不补念、
   她的轨道永不 MISS、提示点敲纸、走完全曲结算；两档各打一遍全 PERFECT，
   **五段数据（准确率 / 接力 x/y / 段内最高连击）与逐音符回放独立重算一致**。

浏览器部分：开场、画布 512×288、字幕条在画布下方且不低于 40px、轨道不压人物、
敲 8 下存下延迟 → 弹档位选择 → 选演播并存进 `act3-difficulty-v1`、倒计时后进演奏且 ON AIR 亮、
音频时钟跟着末段变速、自动弹（按音高按 F/J，故意漏掉每个接力验证补位）、
突发段字幕乱序标红且文字没改、噪音 ≥50 字幕进雪花点状态、`Esc` 退出后停歌不把时钟归零、
跳到结尾自然结算、完成卡五段行、`act3-result-v1` 结构与 stats 一致、
旧存档只留 `offset/cleared/best`、稿纸数变体字幕出现且不动谱面、无 console 报错。

```bash
node act3/tools/shots.cjs   # 出 d1–d11
```

## 接进故事

第二幕 `act2/broadcast-bridge/index.html` 的“两个人都到了”卡片提供“开始广播”，进入本页时带 `?from=bridge`：直接从双人就座进入试音，不重复演出开门和相认。室内复用 `act2/broadcast-bridge/assets/broadcast_room_single_desk*.png`，和臣坐左、朱里坐右，右门通走廊，两支麦克风在同一张桌上。

未完成时的「离开」通过 `?back=` 回到第二幕就座卡片；单独打开时默认返回 `../school-preview.html`。广播完成卡的「一起走出广播室」进入 `../act4/after-broadcast/index.html`，接放学后的白色护栏走廊。

旧存档键 `our-story-act3-broadcast-v1` 语义不变，只存 `offsetMs`（校准值）、`cleared`（是否录完过）、`best`；
难度与分段成绩分别放 `act3-difficulty-v1`、`act3-result-v1`（见上文）。
**不存进度**——音游没法从半句中间接上，`#bye` 卡里那句「下次进来从头再录一遍」就是为这个写的。
