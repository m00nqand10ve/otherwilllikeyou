# 第四幕《我所不知道的事》

独立剧情模块，入口 `act6/index.html`。第三幕收尾 `act5/narrative/index.html?phase=after` 的结尾按钮已接到这里。

目前实现十个大纲事件的顺序叙事、关键对白、CG/场景切换、人物站位、一次还本子选择、事件 02 的课间时机、事件 03 的跨班打听、事件 04 的公告栏布置、事件 05 的信息卡分类、事件 07 的纸飞机、事件 09 的记忆滑块、跨事件存档和结尾；再加上八个日常小游戏，由 `minigames.js` 接进同一个页面。

## 剧情

十个事件按 `story.js` 里的 `events` 数组顺序播放，但玩家不是在菜单里点“下一步”：页面上是一张校园地图，用 A / D 或 ← / →（W / S 或 ↑ / ↓ 调远近）在三班门口、楼梯口、四班门口、二班门口、公告栏、走廊护栏、操场之间自由走动，走到画面边缘就换到相邻区域。走到当前事件发生的地点，按 E / Enter，或点屏幕上的「E 互动 · …」才开场。触屏 / 窄屏会显示屏幕方向键（按住走动，松开停止）和互动按钮；选项可以用 1 / 2 / 3 数字键选，也可以用 Tab 把焦点移到选项按钮上按回车。事件对白和选择进行时，虚拟控制会自动收起。跨事件存档键为 `our-story-act6-v1`。

- `event01` 还本子 · `event02` 由乃的催促 · `event03` 帮我问一句 · `event04` 公告栏 · `event05` 听来的与猜到的
- `event06` 一个名字 · `event07` 纸飞机 · `event08` 由乃说的事 · `event09` 原来在那之前 · `event10` 和平时一样

调试：`__act6.state` 看状态，`__act6.campus` 看当前区域 / 坐标 / 是否在事件点，`__act6.startAt(0…9)` 从指定事件开始，`__act6.reset()` 清本章存档，`__act6.daily('relay')` 直接演一场日常。

### 主线里的玩法

事件 02 / 05 / 09 是 DOM 面板，事件 03 复用日常的画布探索层；对白仍然都是 `#dialog`：

- **事件 02《由乃的催促》**：先选时间点（刚下课 / 课间中段 / 快上课了），再选行动（现在过去 / 等一会儿 / 先去找朋友 / 今天算了）。右上角三格刻度只表示课间走到哪一段，没有倒计时数字。「等一会儿」把时间点往前推一格，第三次等待（或已经「快上课了」还等）打铃，委托留到下一次课间；「今天算了」由乃说「可以。那我去」，下一次课间的第一句换成「想好了吗」。时间窗只决定人流密度和事件 03 的开场白，不改变能问到的信息。写 `timingCompleted`、`timingChoice`、`timingWindow`、`timingWaits`、`timingDeferred`。
- **事件 03《帮我问一句》**：在四班门口 / 走廊 / 二班门口自由走，走近朋友甲或朋友乙按 E（也可以点他，或点屏幕上的按钮）问一次，再选怎么开口。问到的只写成「朋友说的」：`askedFriendA/B`、`bAndAClose`、`bHasCrush`，最高 `reported`；没问到就写 `none`，不写事实。宋遥只在走廊远端左向路过，60px 内被老师叫走，没有 E、不对白。走到二班最右边、或按 F / 点「先回去」可以结束。事实通过 `host.persist` 写进剧情存档，日常存档不碰。
- **事件 04《公告栏》**：四样材料（标题 / 活动照片 / 时间 / 参加方式）拖进四个虚线区域，也可以「先点材料再点格子」，或用 Tab 选材料后按 1–4、Enter 放进当前格。放错不弹错误框、不重来，只由朱里或由乃说一句建议；8 秒不动只帮一次。吸附后允许 0–1 度的歪。四样都放好才写 `bulletinCompleted`，同时记下 `bulletinPlacements`、`bulletinTilts`。由乃的「上次那个事……」只在 4/4 之后说一次（`bulletinYunoEcho`）。如果本周目在目录里玩过传话、`relayLost` 里有物品，朋友甲会把剪刀和水错带到板边，只当一句笑话（`bulletinLostItem`），不进主线。
- **事件 05《听来的，与猜到的》**：五张信息卡分到「听到的 / 我猜的 / 还不知道」。卡片池读事件 03 写下的 `bAndAClose`、`askedFriendA/B`、`bHasCrush`，没问到的条目改成「还不知道」的问法；一条都没问到（直接跳到这一场）时用默认卡组。分得准不准都不重来、不打分，只写 `reportAccuracy`（`accurate` / `mixed` / `silent`）；点「其实，我没问到」直接走 `silent`。事件 08 开场由乃只按这个字段换一句语气。值日表已经回到目录，这一场不再先排表。
- **事件 07《纸飞机》**：由乃先扔（宽翼、飞得很近），再轮到玩家：三种折法（尖头 / 宽翼 / 方头）、← → 调 15°–60° 的角度、↑ ↓ 调力度或按住空格蓄力，松开投掷；最后朱里扔（方头、上下浮动 10%）。没有分数、不排名、不判失败，三种折法都一定飞得出去。写入 `paperPlaneBest`、`paperPlaneStyle`、`paperPlaneWinner`、`paperPlaneLanded`（落点在取景框里的比例）。紧接的拍照会把地上那架飞机画进取景框，拍到的照片会记下 `photoPicked.plane`；事件 09 只复现照片里有的那架，没有就跳过。
- **事件 09《原来在那之前》**：三段各一个 0–100 滑块，左边「那时」、右边「后来」。画面不位移、不改色，只在滑过一半时换旁白、四周略压暗；拖回去可以重读，E / 空格不能跳过。第三段落在没人的傍晚走廊上；如果事件 07 拍过照片，会按 `photoPicked` 的构图用相纸复现一两秒再收掉。中途退出会记 `memorySegmentsSeen`，重走时从下一段续看。
- 这几场的键鼠触屏：02 用数字键 1–3 选时间点、1–4 选行动，↑↓←→ 或点击也都行；03 可以用键盘走、屏幕方向键走、点朋友说话；04 的材料可以拖，也可以先点材料再点格子，Tab 选材料后按 1–4、Enter 放进当前格；05 的卡片可以拖，也可以 Tab 选卡后按 1 / 2 / 3，← → 换栏；07 用 1–3 换折法、← → 调角度、↑ ↓ 调力度、按住空格蓄力松开投掷（Enter 也行），所有按钮都能点；09 的滑块用鼠标 / 触屏拖，或用方向键、Home / End。Esc 统一是「取消这一场」，剧情给「重试这一段 / 先跳过」，出错仍走 `#eventFailure`。

## 小游戏

八个日常都在 `games/`，画在 `index.html` 里一张 512×288 的画布上（`#mg`，尺寸和 `#art` 完全重合，切进切出画面不跳）。玩法规则写在各自的 `games/*.js` 里，自检见本目录的 `tools/check.cjs`。

| 编号 | 游戏 | 类型 | 位置 |
| --- | --- | --- | --- |
| D01 | 一句话经过三个人 | 传话 / 记忆 | 目录 |
| D02 | 穿过课间的人流 | 双轴走位 / 时机 | 剧情 · `event02` 之后 |
| D03 | 留一张照片 | 构图 / 抓拍 | 剧情 · `event07` 之后 |
| D04 | 值日表 | 轻逻辑 | 目录 |
| D05 | 传纸条 | 潜行 / 时机 | 剧情 · `event08` 之前 |
| D06 | 雨里的伞 | 平衡 / 叙事 | 目录 |
| D07 | 课堂笔记 | 筛选 / 记忆 | 目录 |
| D08 | 踢毽子 | 节奏 / 时机 | 目录 |

一周目只走三个（人流、照片、传纸条），传话 / 值日表 / 雨伞 / 课堂笔记 / 毽子五场只在通关后的「日常」目录里。目录里八场都能重玩，标着「一周目」的三场就是主线会走到的那三个；通关前入口不出现，`?daily=1` 仍可直接进目录再单场重演。

- **没有硬失败**：拍糊、传歪、排不出来、撞到人、被老师抓，都只换一段短对白。
- **不写主线事实**：日常用单独的存档 `our-story-act6-daily-v1`，只记「玩过没有」和当场的选择，不碰 A、宋遥、朱里的关系字段。
- **一个对白系统**：游戏里说话还是 `story.js` 的 `#dialog`，推进方式不变（点击 / Enter / 空格 / E）。
- **可以中途退出**：一局里按 Esc，或点右上角的「退出」，结束这一局；剧情收到取消后给「重试这一段 / 先跳过」。毽子的「差不多行了」复用同一套收尾，只在游戏实际进行中可点。
- **触屏与键盘**：人流和校园探索都有屏幕方向键（按住走、松开停）；值日表可以用 Enter 提交，排不出来时点「就先这样」跳过；课堂笔记的要点随广播逐条出现，也可以点「记好了」提前收尾。
- **出错不卡死**：素材没加载上会列出失败项并给「重试」；事件或小游戏抛异常时给「重试这一段 / 回到校园」，存档与事件进度不动。

## 目录与入口

```text
index.html      剧情页（也承载小游戏的画布与面板）
story.js        十个事件 + 对外接口 window.ACT6
events.js       主线里的四场 DOM 玩法：02 课间时机 / 04 公告栏 / 05 信息卡分类 / 09 记忆滑块
events.css      这四场的面板样式（时机刻度、公告栏与四个虚线槽、纸卡、滑块、相纸）
minigames.js    加载资源、接引擎、对白桥接、八个游戏的目录
minigames.css   小游戏、事件 03 / 07 的面板与 HUD
games/          八个小游戏，各自注册到 DAILY.games
games/inquiry.js   事件 03 的打听场景（不是日常，不进目录）
games/paperplane.js 事件 07 的纸飞机（不是日常，不进目录）
tools/check.cjs 自检（Playwright + 本机 Chrome）
```

- `index.html?daily=1` 直接进日常目录。
- `index.html?daily=relay` 直接演一个；主线里的两场也能这样点名：`?daily=paperplane`、`?daily=inquiry`。
- 目录里点哪一场都行，演完回到目录；「回到剧情」收起目录。

## 测试

需要 Node.js、本机 Chrome，以及 `game/dust-corridor` 里装好的 Playwright：

```bash
node act6/tools/check.cjs
```

会跑完八个游戏，验存档字段、工厂异常后的复位、Esc 取消、触屏方向键与互动按钮、选项数字键与 Tab 聚焦；再验事件 02 的时间点 → 行动 → 等一会儿 / 打铃 / 今天算了 / 先去找朋友，时间窗只改人流与打听密度、开场白；事件 03 的问甲、问乙、没问到，`bHasCrush` 只在问到时出现，宋遥被老师叫走且没有 E / 对白，触屏方向键与点朋友说话；事件 04 的四槽四材料、鼠标 / 键盘 / 点击 / 触屏四条放置路径、放错只给建议不判失败、吸附歪角不超过 1 度、板边错带只在 `relayLost` 含物品时出现；事件 07 的三折法、角度 / 力度、按住空格蓄力、三个人各一回合、落点写进照片并在事件 05 / 09 里被读到；事件 05 的卡片池 / 四条操作路径 / 三种结果，以及它读事件 03 的字段；事件 08 的两句开场语气；事件 09 的三段滑块、空走廊、`memorySegmentsSeen` 续看与合照（含那架飞机）复现；一周目只接三场日常、事件 10 不再强制踢毽子、通关后右上角「日常」入口可见且能逐个进入。第三批美术的用例单独一段：举伞帧 / 分层伞 / 老师 12 帧 / 操场三张的全部加载与路径、雨伞的握点与绘制顺序（两人和三人各一遍）、老师三态姿势帧、三场操场背景。截图落在 `act6/tools/shots/`。

## 信息边界

A 和宋遥的关系只作为朋友转述存档；朱里转来前喜欢 A 的事只在事件 08 由由乃说出；由乃的动机不确认。日常小游戏不出现 A、不出现「朱里喜欢谁」，也不把任何日常结果升级成事实。

## 连续步行

校园探索使用共享的 shared/campus-route.js。方向键或 A/D 走到画面边缘即可进入相邻区域，走到主线地点后按 E 继续。小游戏仍按当前剧情占位处理。
