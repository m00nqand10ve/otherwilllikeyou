# 第三幕剧情层 · 藏不住的心事

入口：`index.html`。第四幕栏杆结尾进入本模块；前半段完成后进入 `../daily.html` 的校园日常。校园日常默认按自动时间线推进，整章完成卡指向 `index.html?phase=after`；调试用的单场目录 `daily.html?hub=1` 里也有同一个入口。

整条故事从仓库根目录的 `index.html` 开始（开始页）。「开始完整故事」会清掉第二幕、广播、校园日常和本模块的存档，从第一幕重新走；「继续上次」按本机进度直接接到校园日常或收尾。收尾最后一屏的「回到开头」用 `target="_top"` 跳出第一幕的 `storyframe`，回到开始页，旁边保留「重看这一段」。这样从第一幕到最新收尾是一条连续的流程，收尾不会再落回校园日常里循环。

这里独立实现剧情与心绪，不修改 `act5` 的四个小游戏玩法。和臣在另一个班；朱里与由乃同班。再次见面、一次没有遇见的课间、再次交谈、由乃初次加入、三人选择话题，都按固定日程演出，不随机刷人。

## 心绪系统

`emotion.js` 提供 `StoryEmotion`，有 `encounter`、`familiar`、`quiet` 三种演出。玩家抓住胃部向后拖，调整力度与方向，在心跳缓和的半拍松开，把话送往右侧目标；也可用方向键调整、空格发射。力道、方向或节拍不合时会说错或说不出口，只重开这一小段。每次重试都放宽力度、角度与节拍判定，心绪边缘逐渐变淡；不记录失败次数，也不改写朱里的态度或剧情分支。暖色边缘、和臣脸红近景与心跳声用于前两次；听到由乃消息时改用冷色安静效果。界面不显示百分比或关系数值。

存档键为 `our-story-act5-narrative-v1`，只保存 `firstRegulated`、`metYuno`、`firstTrioTopic`、`introCompleted`、`disclosureHeard`、`likedPersonKnown`、`disclosureReply`、`disclosureRegulated` 等事实与选择。`likedPersonKnown: false` 表示和臣尚不知道是谁，不能被解释成“朱里喜欢别人”。

## 收尾事件的边界

项目聊天确认不再让由乃直说“朱里有喜欢的人”。收尾现在从《体育活动》散场接上：球停在边线外，比分牌已经收起来，三个人往楼里走；朱里说“我先回去一趟”，把本子留给由乃，走得比平时快。两张过门图直接复用 `assets/cg/act5/`：开头是 `story_g04_exit_512.png`（球停、收东西），朱里先走时换 `story_g04_to_corridor_512.png`（她往教室门走，和臣与由乃留下）。走廊里由乃只字未提朱里的心意，而是托和臣去问二班的宋遥“现在有没有喜欢的人”，并叮嘱别让朱里知道她看过本子；本子摊开那页露出的半个名字就是全部暗示。心绪互动后，无论问不问，由乃都把本子递给和臣，让他明天帮她还；结尾停在这件具体的物件上，而不是一句抽象心声。收尾卡的主按钮是「回到开头」：它跳出 `storyframe`，回根目录开始页；「重看这一段」只重播收尾。本子用 `assets/minigame/prop_notebook_open.png`（32×24，摊开）和 `prop_notebook.png`（24×32，合上）两态占位，递接时切换现有 `offer` 帧并用 `moveProp` 平移。这里只把球赛当作已经发生的日常，不写喜欢对象，也不写朱里的去向；待真实回忆补齐时，只替换剧情文本与场面，不动心绪接口和小游戏。

## 验证

在项目根目录运行 `node act5/narrative/tools/check.cjs`，会走通前半段和收尾，并检查收尾卡的「回到开头」（`../../index.html`、`target="_top"`），预览图落在 `tools/`。全流程入口和「继续上次」的接缝由 `node tools/full-story-check.cjs` 检查；第四幕 → 本模块的框内跳转由 `game/dust-corridor/tools/story-chain-check.mjs` 检查。亦可直接用浏览器打开 `index.html`，用 `E` / Enter / 空格 翻页，数字键或点击选项。
