# 第二幕 · 一起完成的黑板报

双击 `blackboard.html` 就能玩。不用构建、不用服务器、不用联网。

## 玩法

走廊开场 → 由乃（朱里的闺蜜）经过，和她打个招呼 → 镜头推近黑板 → **选一个主题** → 画 → 两个人站在板前看成果。旁白带出她是朱里常一起走的朋友；她只在开场短暂出现，使用侧面行走与挥手帧，为后面的校园日常出场铺垫。

开画前对白区会给三个主题：**运动会 / 读书周 / 毕业季**（数字键 `1`–`3` 或直接点按钮；不想选直接画也行，按读书周开始）。主题同时决定三件事：板上的淡线底稿（跑道 / 人像 / 学士帽）、图案面板的推荐组、起始粉笔色。上次画到一半的存档会带着主题一起回来；没有主题字段的旧存档按读书周兜底。

| 操作 | 键 |
| --- | --- |
| 画笔 / 橡皮 / 直线 / 方框 / 文字 / 图案 | `B` `E` `L` `R` `T` `S` |
| 显示 / 隐藏预设底稿 | `G` |
| 换粉笔色（偶尔也用来选递过来的粉笔） | `1`–`6` |
| 稳住椅子（她描顶边时） | `A` / `D` |
| 撤销 / 重做 | `Ctrl+Z` / `Ctrl+Shift+Z` |
| 移动放好的图案 | 用图案工具点住它拖 |
| 微调 / 删掉选中的图案 | 方向键（`Shift` 走 4px）/ `Delete` |
| 对白推进 | `E` 或点击 |
| 离开黑板（随时） | `Esc` 或左上角「离开」 |
| 完成（四区齐了之后） | 点「完成黑板报」或 `Enter` |

四个区都达标，完成按钮才会亮：

| 区域 | 达标条件 |
| --- | --- |
| 标题 | 标题区有字，且至少 2 个字是文字工具写上去的 |
| 边框 | 上、下、左、右四条边各有一半以上被画到 |
| 主图 | 中间画够了，且有一笔超过 40px |
| 装饰 | 下方装饰带或四角放够 3 个图案 |

**板上有层很淡的草稿**——设定上是朱里事先打的稿：虚线边框、标题下划线、主图区一张淡化的图（主题不同，图也不同），底下三个小圈/小旗标出图案该放哪。照着描就行，**画完一块，那一块稿子自己就淡掉**，四块都淡完，板面上就只剩你们俩画的东西。它擦不掉、撤不掉、也不会进导出图。想从白板开始就按 `G` 关掉。

**图案是这一版的重点**。按 `S` 展开图案面板（花草 / 天空 / 校园 / 装饰 四组，18 个，按当前主题把推荐组排前面），点一下板面就放下一个，跟着当前粉笔色走。放下之后它是**东西不是像素**：能拖、能方向键微调、能被橡皮整个擦掉、能撤销。所以「放歪了再挪回来」这件事才成立。

### 她这一版多做三件事

- **接力描线**：她偶尔在主图空白处起一小笔（30–60px），末端亮一个闪点，**6 秒**内你从端点附近（12px）落笔就算接上——她会念一句，然后从端点再补一小截把两笔连起来。没接上就自然淡掉，不算失败；她冷却完照常帮忙。这一笔也只算一次辅助，`Ctrl+Z` 一次整笔撤掉。
- **递粉笔二选一**：连用同一支粉笔画一会儿，她会递两支过来（对白区里选，数字键 `1` / `2` 或点按钮）。你挑一支自用，**她用没被选的那支**去补装饰区——颜色是两个人一起定下的。
- **椅子描顶边（这一段是第二幕的记忆点）**：主图达标、但上边框还空着一半时，她说要踩椅子把顶边补完。镜头推近板面上沿，出现一根晃动指针：**按住 `A` / `D` 把指针压在绿区里**，她才落笔，指针出界只是停笔等你——不失败、不重开。约 6 秒描完，她说完两句，镜头退开，两个人站在板前看。

## 完成结算：她评价的是这幅画

四区齐了以后完成，她会在结尾对白里说 **2–3 句指向这幅画具体特征**的评价——不是「你们真棒」，而是带数字的：

- 配色（用了几种粉笔色 / 只有一支笔的干净）
- 主图填充率（填得满 / 留白透气）
- 左右笔迹量（差不多重 / 哪边偏沉）
- 装饰数（摆了 4 个以上 / 克制留白）

评价句写在 `lines.js` 的 `DONE_EVAL` 里，每句都有 `when(stats)` 条件，只有板上真的长成那样才会被选中。结果落进新键 `our-story-act2-board-eval-v1`：

```js
{ theme: "reading", themeName: "读书周",
  evalIds: ["color-many", "fill-low", "pattern-few"],
  evals: [{ id: "color-many", text: "用了3种粉笔色，……" }, …] }  // 和 evalIds 一一对应、同序
```

广播桥的开场对白会引用这里的主题 + 第一句评价；第四幕的 `boardMemory` 也读同一份（不同页面不 import 本模块，所以整句文本一起存进存档）。

朱里会自己补边框、往装饰区添图案、把挤在一起或压出格子的图案挪正、点星星、递粉笔。
她只在空白处落笔，不擦你的东西，挪图案时也只改位置、不碰你画的线，
一次辅助按一次 `Ctrl+Z` 就整笔撤掉，全局最多 6 次——她不会替你画完。

**画板期间她一直在说话**，走画布下面那条对白区：左边朱里、右边和臣，中间一个对话框，
谁说话谁亮起来、尾巴指过去，两个人还会错开眨眼。整条在画布**外面**，黑板一点都不被挡。
内容大部分是日常闲聊（抽卡、开黑、追的选秀、食堂、月考、周末），只有少数几句和这块板有关——
干活时聊的本来就是这些零碎事。她补完边框、你擦掉东西，那些事件台词也走同一条。
结尾那几句也在这儿，按 `E` 推进，读完两个人才退场、完成卡才出来。

**随时可以走**。按 `Esc` 或点左上角「离开」，她会说一句，画面压暗，推出「先到这儿」卡：
「接着画」回板前，「离开」跳回去（默认 `../school-preview.html`，接宿主时用 `?back=` 指定）。
走之前一定存盘，下次进来接着这张画。

## 自检

```bash
node act2/tools/check.cjs
node act2/broadcast-bridge/tools/check-handoff.cjs
```

`check.cjs` 的断言组：板面几何、底稿不算笔迹、底稿按区淡出、底稿开关与复位、画稿不越出主图区、
字幕一直在滚、对白区是两个像素小人且不压板、对白区高度不跟着字数变、
字幕内容是闲聊（六成以上不提画板）、四区互不误判、
图案面板与缩略图、图案放/拖/微调/撤销、橡皮删图案、文字工具真实路径、
她不覆盖已有笔迹、她的一笔可一次撤销、她自己放图案、她挪正挤在一起的图案、
导出 PNG、完成镜头用玩家作品、自然触发、刷新后存档恢复、中途退出与回来。

设计文档 §1.7 新增的断言也在这份里：

- **主题**：开画前三个选项都在对白区；三个主题的底稿构图（画稿指纹 / ghostKey）、
  图案推荐组、起始粉笔色互不相同；选完主题字幕照常滚、选择题收起；图案面板仍有 18 个。
- **椅子描顶边**：主图达标 + 上边框 < 50% 时触发、触发时锁住玩家画笔；
  按住 `A` 能把指针压出绿区，出界期间进度不涨、只累计停笔时间，场景仍是 `board`；
  压回绿区能描完 6 秒，上边框覆盖率涨过 50%，说完两句专属对白、镜头退回、板面解锁。
- **接力描线**：`girl.force()` 产出 `relay`，起笔长度在 30–60px；端点高亮；
  真实鼠标从端点 12px 内落笔能接上并念 `LINES.relay`，接上不再多算辅助；
  `Ctrl+Z` 一次撤掉整笔、端点熄灭；不接 6 秒后自动淡掉，不算失败、不锁板。
- **粉笔二选一**：连用同色三次触发，对白区摆两支且颜色不同；选一支后当前色就是它，
  她补的装饰色是**没被选**的那支。
- **结算聚合**：手工构造一块已知板面，`colorCount / patternCount / fillRatio /
  balance / left / right` 与独立扫描逐项对账。
- **结算评价写档**：完成时写 `our-story-act2-board-eval-v1`，`theme/themeName` 正确，
  `evalIds` 2–3 个、都在 `DONE_EVAL` 里，`evals` 与 `evalIds` 一一对应同序、
  文本真的在结尾对白里说出口，同一块板重算结果可复现。
- **旧存档兼容**：把存档里的 `theme` 字段删掉再刷新，仍按读书周读入、能接着画、
  不再弹主题选择题、不报错。

`check-handoff.cjs` 覆盖广播桥：既有递稿姿态 → girlSit；第二幕主题 + 评价句的回响
（没有结算存档时不多说）；分镜 03 风吹稿纸（3 张、落点由种子决定且两次加载一致、
按 E 能接、接住数写 `our-story-bridge-papers-v1`、缺省读 3、飘纸时不拦路、能走到门口）。

最后两条会真的把页面跳到 `../school-preview.html`，所以排在最后。

## 接进故事（已做）

模块现在真的接在故事里：第一幕手记打完后，`school-preview.html?start=1` 装进第一幕页面内的
全屏 `#storyframe`，之后黑板报、广播室、晚间广播、广播后的走廊都在这个框里继续走，
直到 `act4` 结尾靠栏杆的 CG。外层页面不换页，焦点交给框。

接线方式：

- 进入黑板视图：`school-preview.html` 跳到 `act2/blackboard.html?back=../school-preview.html`。
- 完成或离开时：完成卡的「继续 · 广播室」、先到这儿卡的「先去广播室」都跳到
  `act2/broadcast-bridge/index.html?board=done|deferred`。
- 广播室再过 `act3/broadcast.html?from=bridge`，最后到 `act4/after-broadcast/`。
- 第一幕的幕卡仍写「E 进入第二幕 / R 重看第一幕」；进入后不再跳页。

事件口仍然保留（`board:start` / `board:region` / `board:assist` / `board:leave` /
`board:quit` / `board:finish`），外面若再接别的宿主可以直接用。
