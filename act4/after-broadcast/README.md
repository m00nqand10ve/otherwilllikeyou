# 晚间广播后 · 白色护栏

入口：[index.html](index.html)。第三幕广播完成卡的「一起走出广播室」直接进入本模块；也可以双击独立预览。结尾的「继续 · 藏不住的心事」进入 `../../act5/narrative/` 的独立剧情层。

这是附带的下一幕指导稿在本项目里的实现：广播室右门外仍是项目已有的红砖／白瓷砖门侧走廊；镜头转到护栏一侧后，沿用现有 `school_corridor_railing_pixel.png` 的空间。楼梯口补了一张同构图背景，最后的背面靠栏杆画面沿用 `cg_corridor_lean_back.png`。没有把指导稿里泛称的场景当成另一所学校。

## 流程

1. 两人从广播室右门出来，门轻轻关上；聊几句刚才的广播。
2. 玩家按住 `A` / `←` 往左走，朱里贴近跟随。可在门侧走廊的教室窗前按 `E` 看一眼。
3. 镜头切到白色护栏一侧。两人聊作业；朱里叫住和臣，玩家按 `E` 在护栏边和她说话，再继续往前走。
4. 一张广播稿从朱里身边被风吹起，飘落在前方。玩家走近后按 `E`，和臣弯腰捡起，两人一起把纸角压平、夹好。
5. 留出一段没有对白的路。朱里递来一块饼干，和臣先停步转身面向她，才切入两人递饼干的 CG；玩家继续走路后才接过。
6. 到楼梯口，两人先停在护栏前。玩家按 `E` 靠过去，聊完饼干和下一次一起走的事，再切到两人背对镜头靠栏杆的既有 CG。
7. 在靠栏杆的画面上，教室门口、黑板报、广播室与刚才递饼干的回忆碎片从四角依次汇拢。中央浮现朱里的像素特写，最后由和臣的心声说出自己是怎样慢慢喜欢上她的。
8. 回忆退去后，和臣的脸红特写出现。朱里问他怎么了；他慌忙道别，镜头回到楼梯口，和臣快步离开，朱里留在原地轻声说“明天见”。

右上角的「继续往前走」是鼠标／触屏的行走入口，再点一次「停一会儿」会停下。护栏谈话、捡起稿纸与递零食后需再次继续走；楼梯口需要主动走到朱里身边。走廊提示改为底部「旁白」字幕，简短按键说明保留在字幕角落；行走对白出现时角色会停步，可按 `E`／Enter 或点击翻页，也会定时继续。结尾可重看或返回广播。广播小游戏本体没有改动判定规则。

## 前两幕的回响

这一场会读两个其它页面写的 `localStorage` 键，只换台词、不换流程：

- `our-story-act2-board-eval-v1`（第二幕结算时写）：主题名和当时她说的一句评价。
  结尾回忆里的黑板报那句会引用它们（「她说这期做『运动会』……『左边留白多，反而透气』」）。
- `act3-result-v1`（第三幕结算时写）：开场那段对白按结果分三档——接力全接住 /
  被她补位 ≥2 次 / 一般完成。三档走向与后面的剧情完全一样。
- 两个键缺失（旧存档、没玩过前两幕）时一律走原来的台词，不报错也不清档。

编译检查用 `node act4/after-broadcast/tools/check.cjs`：主流程之外还会分别注入
这两组存档，断言三档变体、主题/评价引用和缺省回退。
